## Đưa lên GitHub Pages

```bash
git init
git add .
git commit -m "Add vocabulary site"
git branch -M main
git remote add origin https://github.com/<ten-ban>/<ten-repo>.git
git push -u origin main
```

Sau đó vào **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**. Trang sẽ có tại `https://<ten-ban>.github.io/<ten-repo>/`.
